# Seven Android games

Prototype APK downloads, version 0.1.0. Android 8.0 or later.

No ads, no in-app purchases, no live ad revenue. Direct APK downloads, not app-store releases. Development-signed builds; compatibility has not been verified on every Android device. Keep Play Protect enabled.

## Games

- Spark Sprint
- קפיצת מסלול
- רשת פנסים
- אקו צלילים
- מגדל פרוסות
- מכרה מהיר
- שובל כוכב

Download the APKs from the repository file list or release assets. Source code and signing keys are not included.
